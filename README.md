# TrashNet: MobileNetV2 vs CNN

A binary waste classification project comparing **MobileNetV2** (transfer learning) and a **Custom CNN** (trained from scratch) using the TrashNet dataset augmented with additional trash images from Kaggle.

## Overview

This project trains and evaluates two deep learning models for binary waste classification:

- **MobileNetV2**: Lightweight pretrained model with frozen feature extraction and a fine-tuned binary classifier head
- **Custom CNN**: 3-layer convolutional network trained from scratch with BatchNorm and AdaptiveAvgPool

Both models classify an input image as either **garbage** (non-recyclable) or **non_garbage** (recyclable).

### Key Features

- Binary classification: garbage vs. non_garbage
- Custom Focal Loss combining BCE, focal weighting, and class penalty to address class imbalance
- Data augmentation: random rotation, horizontal flip, and resized crop
- Model versioning with timestamp-based checkpoint directories
- Per-class and macro evaluation metrics with confusion matrix output

## Dataset

**Primary source**: [TrashNet](https://github.com/garythung/trashnet) (Stanford CS229, Gary Thung & Mindy Yang) — MIT License  
6 classes: cardboard (403), glass (501), metal (410), paper (594), plastic (482), trash (137). Total: 2,527 images.

**Supplementary source**: [Kaggle Garbage Classification](https://www.kaggle.com/datasets/mostafaabla/garbage-classification) (mostafaabla) — 697 additional trash images added to the trash class.

**Binary remapping**:

| Label | Source classes | Count |
|-------|---------------|-------|
| non_garbage (recyclable) | glass, paper, cardboard, plastic, metal | 2,390 |
| garbage (non-recyclable) | trash (TrashNet 137 + Kaggle 697) | 834 |
| **Total** | | **3,224** |

**Dataset split** (random seed 2150):

| Split | Proportion | Approximate count |
|-------|-----------|------------------|
| Train | 70% | 2,257 |
| Validation | 15% | 484 |
| Test | 15% | 483 |

|--------|-------------|------------|
| Accuracy | 93.37% | 90.48% |
| Garbage Precision | 82.35% | 81.36% |
| Garbage Recall | 93.33% | 80.00% |
| Garbage F1 | 87.50% | 80.67% |
| Non-garbage Precision | 97.69% | 93.42% |
| Non-garbage Recall | 93.39% | 93.94% |
| Non-garbage F1 | 95.49% | 93.68% |
| Macro F1 | 91.50% | 87.18% |

Garbage Recall is the primary evaluation metric for this application, as missing actual garbage (false negatives) is the most costly error.

## Dataset Preparation

1. Extract `dataset.zip` to obtain the 6-class folders. Place them under `trashnet/trash/`:

```
trashnet/trash/
├── cardboard/
├── glass/
├── metal/
├── paper/
├── plastic/
└── trash/
```

2. Run the preprocessing script to remap to binary classes and generate the train/val/test split:

```bash
python scripts/step1.py
```

This script will:
- Remap glass, paper, cardboard, plastic, and metal to `non_garbage`
- Remap trash to `garbage`
- Shuffle with random seed 2150 and split 70/15/15
- Write the split dataset to `trashnet/trashnew/`

## Training

```bash
python scripts/step2.py
```

Key hyperparameters (editable at the top of `step2.py`):

| Parameter | Value | Description |
|-----------|-------|-------------|
| EPOCHS | 10 | Training epochs |
| BATCH_SIZE | 64 | Batch size |
| IMAGE_SIZE | 224 | Input image size (px) |
| MOBILENET_LR | 0.001 | MobileNetV2 learning rate |
| CNN_LR | 0.0001 | CNN learning rate |
| FOCAL_GAMMA | 2.0 | Focal loss gamma |
| GARBAGE_PENALTY_MULTIPLIER | 1.5 | Additional weight multiplier for garbage class |
| RANDOM_SEED | 42 | PyTorch seed for reproducibility |

Training output is saved to `models/{TIMESTAMP}/`:
- `MobileNetV2.pth` and `CNN.pth` — model weights and training history
- `MobileNetV2_info.json` and `CNN_info.json` — metrics and hyperparameters
- Accuracy and loss plots per model
- Confusion matrix plots per model

### Loss Function

The custom loss combines three components per sample:

```
loss = BCE_loss x focal_factor x sample_weight

focal_factor = (1 - p_t) ^ gamma        # penalises hard/misclassified samples
sample_weight = class_weight x garbage_penalty   # addresses class imbalance
```

Class weights are computed from the train split counts using a square-root scaling to avoid excessive weight on the minority class.

### Model Architectures

**MobileNetV2**

- Backbone: MobileNetV2 pretrained on ImageNet (all feature layers frozen)
- Classifier head: Dropout(0.3) → Linear(1280 → 1) → sigmoid
- Trainable parameters: ~1,281

**Custom CNN**

```
Conv2d(3, 32, 3x3) + BatchNorm2d + ReLU + MaxPool2d(2x2)
Conv2d(32, 64, 3x3) + BatchNorm2d + ReLU + MaxPool2d(2x2)
Conv2d(64, 128, 3x3) + BatchNorm2d + ReLU + MaxPool2d(2x2)
AdaptiveAvgPool2d(1x1)
Flatten → Dropout(0.3) → Linear(128 → 1) → sigmoid
```

- Total trainable parameters: ~385K
- No pretrained weights

## Checkpoint Format

Each model generates two files per training run.

`{MODEL_NAME}.pth` contains:

```python
{
    "model_state_dict": {...},
    "history": {
        "train_acc": [...],
        "val_acc": [...],
        "train_loss": [...],
        "val_loss": [...]
    },
    "metrics": {...},
    "params": {...}
}
```

`{MODEL_NAME}_info.json` contains the same metrics and params in human-readable JSON for quick inspection without loading the model.

## Troubleshooting

**FileNotFoundError: trashnet/trash not found**  
Ensure the dataset folders are placed at `trashnet/trash/` before running `step1.py`.

**CUDA / MPS out of memory**  
Reduce `BATCH_SIZE` in `step2.py`.

**High false negatives on garbage class**  
Increase `GARBAGE_PENALTY_MULTIPLIER` (e.g., 2.0) or `FOCAL_GAMMA`.

**Model accuracy plateaus early**  
Increase `EPOCHS` or adjust learning rates.
